# 图片素材

本目录用于存放世界观项目中的**图片素材**。

这些图片不预设为“设计参考图”。其中一部分可能直接用于网站展示、地图页面、地区页面、角色页面或其他前端内容；具体用途和网页位置以创作者后续指示为准。

## 使用规则

- 图片素材由创作者确认后再正式归档。
- 不自行判断图片最终应该展示在哪里；创作者会明确指定使用位置。
- 每加入一张正式图片，同时增加一个同名的 Markdown 说明文件，例如：
  - `evernight.png`
  - `evernight.md`
- 说明文件记录：
  - 图片用途；
  - 网页/项目中的指定使用位置；
  - 必要的展示说明；
  - 其他创作者明确要求保留的信息。
- 不把“临时生成但未选用”的图片放入正式素材目录。
- 如果图片被替换，以最新明确确认的版本为准；如有必要在说明文件中记录替换情况。

## 说明

图片本身是正式项目素材，说明文件只是帮助 Codex 和后续维护者理解图片应该如何使用，不能擅自把说明中的推测扩展成世界观设定。
