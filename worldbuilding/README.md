# 世界观设定源文件

本目录是《三国大洲》世界观的设定源文件（source of truth），供 ChatGPT 与 Codex 共同读取和维护。

## 使用规则

1. 只把已经由创作者明确确认的设定写入正式文件。
2. 讨论中的方案、候选方案和未确认内容，不得当作正式设定；如确有必要记录，必须明确标注“待定”。
3. 如果新讨论与旧设定冲突，以最新明确确认的设定为准，并同步修改旧内容。
4. 不要为了让设定看起来完整而自行补全缺失信息；缺什么就保留什么。
5. 本目录优先于网站展示层数据。docs/data/world.json、docs/data/map.json 等属于网站发布数据，可以根据本目录的正式设定更新。
6. 地图的精确边界、坐标和矢量数据仍以地图编辑器工程为准；文字设定不要擅自修改地图几何。
7. 当创作者明确要求“同步世界观”或类似指令时，将本轮以来已经确认的设定整理到本目录，并保持结构清晰，方便 Codex 后续读取和更新网站。
8. 修改正式设定时，尽量保留历史可追溯性，在 CHANGELOG.md 简要记录重大变更。

## 当前目录

- global-rules.md：全世界观通用规则。
- countries/：国家级设定。
- regions/：地区级设定。
- CHANGELOG.md：重大设定变更记录。

## 设计层级

- 一级：宏观设计——国家、地区框架、神器、授印体系、大洲地理。
- 二级：区域设计——地区地理、城市聚落、经济、社会、授印能力与区域特色。
- 三级：重点地标设计——首都、主要城市、宫殿、学院、遗迹、组织据点等。

当前主要推进：一级基本完成，二级从阿斯特兰帝国的王都地区开始。
